The WTF Report

“Where're The Financials?”
Version 1.9.0 August 2026 Setup & Reports Guide

The WTF Report (yes, it stands for “Where're The Financials?”) is a small Chrome extension that adds seven ready-to-run reports to your ShopView account — including several that ShopView doesn't offer as an export today. It lives in your browser, works on top of the ShopView login you already have, and every report exports to CSV (opens straight in Excel) and Print → Save as PDF.

✓  Safe by design

The extension is read-only: it never creates, edits, or deletes anything in ShopView, and it never sends or emails anything. It simply reads your data to build reports, using the ShopView session already active in your browser — no passwords, tokens, or API keys are stored anywhere.

What's inside — at a glance

WIPWork In Progress — the dollar value of open, not-yet-invoiced work, with margins and shop-floor detail.
WO ReviewWork Order Review — a printable per-work-order breakdown: parts with margins, labor by tech & date, time-clock punches, totals.
Tech LaborTech Labor — labor dollars billed and billed hours per technician for any period.
SalesSales export — ShopView's Performance → Sales report, finally exportable.
A/PAccounts Payable — Aging Summary, Unpaid Invoices, and Aging Detail as CSV or print.
VelocityPart Velocity — how fast every inventory part moves, with on-hand and last-sale data.
InvoicesBulk invoice download — every invoice for a customer as individual PDFs in one ZIP.

What you'll need

  • Google Chrome (Microsoft Edge and Brave work the same way — Edge users open edge://extensions instead).
  • Your normal ShopView login at app.shopview.com.
  • About two minutes. There is no installer to run — you download a folder and point Chrome at it.

1Download the extension

Download link
https://drive.google.com/drive/folders/1shPJMmYjen_p94UGiit8oC1rlky3EJJ7
  1. Open the link above. It's a Google Drive folder named wtf-report-extension.
  2. Click the folder name wtf-report-extension at the top of the page and choose Download. Google packs the folder into a single ZIP file and downloads it.
  3. Unzip it. On Windows: right-click the ZIP → Extract All… On Mac: double-click the ZIP. You'll end up with a folder called wtf-report-extension.
  4. Move that folder somewhere permanent — for example Documents. Chrome runs the extension straight from this folder, so don't delete it or leave it in Downloads where it might get cleaned up later.

2Install it in Chrome (one time)

  1. In Chrome, type chrome://extensions in the address bar and press Enter.
  2. Turn on Developer mode — it's a toggle in the top-right corner of the page.
  3. Click the Load unpacked button that appears in the top-left.
  4. Select the unzipped wtf-report-extension folder and confirm.
  5. A card named “The WTF Report” appears in your extension list — you're done. Optionally, click the puzzle-piece icon next to Chrome's address bar and pin The WTF Report so its icon is always visible.
Why “Developer mode”?

This extension is shared privately with ShopView customers instead of through the public Chrome Web Store, so Chrome uses its “unpacked” install method. If Chrome later shows a reminder about developer-mode extensions, that's expected — the extension keeps working normally.

3Run your first report

  1. Log into ShopView at app.shopview.com as usual.
  2. Look for the blue Reports tab docked on the right edge of the page (about two-thirds of the way down), or click the extension's toolbar icon. The panel slides out and docks on the right — you can drag its edge to resize it, and there's a dark-mode toggle in the header.
  3. Check the account shown at the bottom of the panel — that's whose data the reports will pull. If it's not the right one, switch accounts in ShopView first.
  4. Pick a report tab, set your options, and click Run report. The finished report opens in a new browser tab with sortable tables, summary tiles, CSV export, and Print → Save as PDF.

Keeping it up to date

The extension checks for new versions on its own and shows a desktop notification when an update is ready. When that happens:

  1. Download the latest wtf-report-extension folder from the same Drive link on page 2 and replace the contents of your saved folder. (If your folder syncs via Google Drive for desktop, the files update by themselves — skip this step.)
  2. Open chrome://extensions and click the reload ↻ icon on “The WTF Report” card. That's it.

The reports, one by one

Every report is read-only, opens in its own tab, and offers CSV export and Print → Save as PDF. Long-running reports show live progress and a Stop button — stopping still gives you a clearly-labeled partial report.

WIPWork In Progress — open work, in dollars

The value of everything that's open but not yet invoiced — the same scope and financial columns as ShopView's official WIP report, plus operational detail the official report doesn't show.

  • Options: choose which statuses to include (quick buttons: Select all / All unbilled / In shop only / Clear — “All unbilled” matches the official report), plus an optional Created On date range for faster runs.
  • Financial columns per work order: Approved Total, Labor & Parts Sell, Labor & Parts Cost, Shop Supplies, Discounts, Tax, Total, Margin, and Margin %.
  • Operational columns: line counts, parts to order / in stock, vehicle on site, techs clocked in, estimated hours, progress %, VIN, plate, service advisor, tech, mileage, engine hours.
  • Summary up top: work-order count, Total WIP $, Total Margin $, Overall Margin %, vehicles on site, techs clocked in, parts to order / ready to pick — plus a by-status breakdown and a top-10 chart.
Large sets take a few minutes — the report reads each work order individually. Progress is shown; Stop gives a labeled partial report.

WO ReviewWork Order Review — the printable “internal invoice”

One printable document per work order with everything an owner checks before invoicing: a snapshot with customer & asset info, summary tiles, labor by tech & date (per-day hours and value, per-tech subtotals), per-line cards (labor sessions · parts with unit cost / sell / margin % · pending part requests · tech story), invoice totals with tax, payments and open balance, and a time-clock audit of every punch — with OPEN flags for techs still on the clock.

  • Input: up to 10 work-order numbers, comma-separated — S1-2343 or just 2343 both work (a location dropdown resolves bare numbers). Combined into one document with a page break per work order. Works on invoiced and paid work orders too.
  • Use current: one click fills in whatever you're looking at — on a work order it takes that WO; on a customer profile it pulls all of that customer's work orders; on the Work Orders list it takes whatever the active tab is showing (25 per report, with a pager when there are more).
  • Export: Print → Save as PDF (print-optimized, US Letter), or a CSV ZIP with six flat files per work order (labor by tech & date, labor sessions, punches, parts, lines, summary).
Internal use: this report shows your costs and margins — it's for your team, not something to hand to your customer.

Tech LaborTech Labor — billed dollars & hours per technician

The per-technician numbers shops ask for at payroll or bonus time: labor dollars billed and billed hours for a date range, with actual logged and clocked hours right next to them.

  • Period: This week / Last week / This month / Last month (weeks start Monday), or custom From/To.
  • Scope: work orders invoiced in the period; an optional checkbox also includes unbilled work orders created in the period, shown as separate Invoiced $ / Unbilled $ / Total $ columns.
  • Fair attribution: each line's invoiced labor value is split across the techs assigned to it (weighted by logged time, then time estimates), so flat-rate and discounted lines still count and the report total reconciles with what you actually invoiced. Lines with no tech assigned appear on an (Unattributed) row instead of silently disappearing.
  • Columns: Tech, WOs, Billed Hrs, Labor $ Billed, Avg $/Hr, Logged Hrs, Clocked Hrs — plus cross-check tiles against ShopView's own Sales totals for the same period.
A full month of invoiced work orders takes a few minutes; progress and Stop are shown.

SalesSales — the Performance → Sales report, exportable

ShopView's Performance → Sales report has no export button — this gives it one.

  • Period: one-click presets (This month / Last month / Last year / Yesterday) or a custom From/To range.
  • One row per invoice: labor, parts, and total Sell, Cost, Profit, Margin %, plus hours worked and invoiced.
  • Summary tiles: Total Invoiced, Total Profit, Total Margin %, Labor / Parts Invoiced, Hours.

A/PAccounts Payable — three reports with no export button, exported

Downloads ShopView's own A/P reports as CSV or print. Pick a report and an as-of date (defaults to today).

  • Aging Summary — one row per vendor with aging buckets (Current / 1–30 / 31–60 / 61–90 / 91+) and totals per bucket plus Total Payable.
  • Unpaid Invoices — one row per open vendor invoice: Vendor, Invoice #, Type, Date, Due Date, Past-Due days, Amount, Open Balance, Location.
  • Aging Detail — every open invoice grouped by aging bucket.

VelocityPart Velocity — how fast your inventory moves

For every inventory part: Qty Sold (net), # Work Orders, Last Sale, Last Received, Avg Monthly, On-Hand, Days Since Sale, Vendor, and a Movement rating. Pick a date range, with optional vendor and movement filters. Sortable table, top-10 chart, CSV, print.

The report checks each part's history individually, so large catalogs take a few minutes — the vendor filter is the easiest way to narrow a run.

InvoicesInvoices — bulk-download a customer's invoice PDFs

ShopView can only email a customer one combined statement — there's no way to download their invoices in bulk. This grabs each invoice as its own PDF and bundles them into one ZIP. It never sends or emails anything.

  • Type the customer's account name → Find → pick the exact match from the dropdown.
  • Choose All invoices (paid + unpaid) or Unpaid only, plus an optional invoice date range.
  • Click Download ZIP — each PDF inside is named by its invoice number (e.g. S-2275.pdf). If any single invoice fails to fetch it's skipped and counted in the log, and you still get the rest.

FAQ & troubleshooting

Is it safe? What can it touch?
It's read-only — it never creates, changes, or deletes anything in ShopView, and never sends or emails anything. It runs only on app.shopview.com, uses the login already active in your browser, and stores no passwords or keys. You can remove it any time from chrome://extensions.
A report failed, or the log shows 401 / 403.
Your ShopView session expired. Refresh app.shopview.com, log in again, and re-run the report.
I don't see the blue Reports tab.
Make sure you're on app.shopview.com, then refresh the page. Still missing? Open chrome://extensions, check “The WTF Report” is switched on, click its reload ↻ icon, and refresh ShopView. Clicking the extension's toolbar icon also opens the panel directly.
The report is taking a while.
WIP, Velocity, WO Review and Tech Labor read each work order or part individually, so a few minutes for a big date range or catalog is normal. The panel shows live progress, and Stop always gives you a labeled partial report. Narrower dates or a vendor filter make runs much faster.
A money cell shows “—” instead of a number.
That work order's detail lookup didn't answer during the run — the report's log shows how many were affected. Re-running usually fills them in.
Chrome mentioned “developer mode extensions” when it started.
Expected — that's Chrome's standard note for any extension installed outside the Chrome Web Store. The extension keeps working normally.
